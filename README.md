# Driving in the Motor City

Data and code for Driving in the Motor City project for The Detroit News.

Data:
 - Bridge Conditions (SEMCOG): Bridges are an important part of the road system. Identify the most heavily used bridges in worst condition and see if it explains certain driving headaches in that area.
 - Transportation Improvement Projects (SEMCOG): Use to match where local, county and state agencies are addressing poor roads and where they are not. Compare with crash data and pavement conditions data.
